# Math Wars ⚔️🃏

Juego de cartas educativo hecho con **pygame**, inspirado en *Card Wars*
(el juego de Jake y Finn en Hora de Aventura).

Para jugar una carta tienes que **resolver un reto de matemáticas**:
mientras más cara la carta, más difícil la pregunta.

## Ejecutar
```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Estructura
```
main.py            # punto de entrada
src/settings.py    # constantes y colores
src/game.py        # bucle principal
```
